# 텍스트 위험 분석 API 상세 문서

문서 이슈 #15의 추가 문서입니다. 관련 기능 이슈는 #14입니다. 기능 PR 병합 전에도 문서 브랜치로 공유할 수 있으며, 기능 반영 후 같은 text-ai 서비스의 문서로 연결합니다. API 오류·상태 확인 스키마와 실행 장치 설정을 보완한 기능 변경에 맞춰 설명을 갱신합니다. 문서 브랜치에는 실행 코드를 복사하지 않으며 모델·가중치·판정 임계값을 변경하지 않습니다.

- [API 상세 명세](API_SPEC.md): 요청·응답·제한·판정·오류, 실행 장치 정책과 OpenAPI 대응
- [BE 연동 설명](BE_INTEGRATION.md): 내부 AI API 연결, 추가 검토·오류 전달 및 담당자 확인 항목
- [과거 PB-23 보고서](PB23_REPORT_20261020.md): 과거 팀원 공유 호출 기록. 이번 문서 작업의 재측정 결과가 아님
- [실행 설명](INSTALL_WINDOWS.md): 기능 PR에 포함된 문서
- [저장된 OpenAPI](openapi.json): 기능 브랜치에서 오류·health 응답 모델과 상태·헤더 설명을 보완한 계약 파일

문서 확인 범위는 로컬 코드·스키마·문서 예시의 정적 대조입니다. 기능 변경의 대역 서비스·작은 모델 회귀 테스트와 실제 GPU·OCR·BE 호출은 구분합니다. 실제 FE·BE 담당자 확인, 새 OCR·운영 HTTP 호출 및 전체 통합·성능 검증은 별도로 남아 있습니다. 과거 PB-23 보고서는 이번 수정 결과로 덮어쓰지 않습니다.

이 폴더는 설명 문서이며 독립 실행 패키지가 아닙니다. 기능 PR 병합 전의 문서 브랜치에서는 실행 설명·OpenAPI 링크 대상이 없을 수 있습니다. 기능 코드가 반영된 뒤 합친 구조에서 연결을 확인합니다.
