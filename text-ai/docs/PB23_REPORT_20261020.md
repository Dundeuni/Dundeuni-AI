# [PB-23] 핵심 AI 테스트·응답 지연 확인·연동 결함 점검 보고서

## 1. 테스트 목적

텍스트 직접 입력 및 문자 캡처 이미지에 대한 AI 분석 API의 정상 동작을 확인하고, 처리 시간과 검토 필요 사유가 응답에 정상적으로 전달되는지 점검하였다.

본 보고서는 BE 담당자가 공유한 테스트 결과를 기준으로 작성하였다.

## 2. 테스트 구성

- **서버:** FastAPI 기반 AI 서버, ngrok HTTPS 주소로 외부 접근
- **분석 모델:** A.X-Encoder-base
- **이미지 문자 추출:** PaddleOCR
- **입력 방식:** 직접 입력한 텍스트 및 문자 캡처 이미지

직접 입력한 텍스트는 OCR 없이 분석하며, 캡처 이미지는 OCR로 본문을 추출한 뒤 사기 위험을 분석한다.

## 3. 테스트 결과

### 3.1. 텍스트 직접 입력

일반적인 회의 안내 문장을 입력하여 BE 호출과 분석 결과 반환을 확인하였다.

| 항목 | 결과 |
|---|---|
| API | `POST /internal/v1/text-analyses` |
| BE 응답 코드 | `ANALYSIS202` |
| 처리 상태 | `COMPLETED` |
| AI 판단 | `normal` |
| 위험 점수 | `0.00053578` |
| 추가 검토 필요 | `needsReview: false` |
| AI 처리 시간 | 약 **21ms** |

일반 안내 문장에 대해 정상 판정이 반환되었으며, BE 응답에서 분석 완료 상태를 확인하였다.

### 3.2. 문자 캡처 이미지 분석

문자 캡처 이미지를 전달하여 OCR 수행과 텍스트 위험 분석 결과 반환을 확인하였다.

| 항목 | 결과 |
|---|---|
| API | `POST /internal/v1/text-analyses/image` |
| 입력 유형 | `sourceType: SCREEN_CROP` |
| HTTP 응답 | `200` |
| 처리 상태 | `COMPLETED` |
| OCR 사용 | `ocrUsed: true` |
| AI 판단 | `phishing` |
| 위험 점수 | `0.99804294` |
| 처리 시간 | 약 **6.8초** |
| 추가 검토 필요 | `needsReview: true` |
| 본문 영역 불확실성 | `layoutUncertain: true` |
| 검토 사유 | `UNCERTAIN_MESSAGE_LAYOUT` |

이미지에서 텍스트를 추출한 뒤 위험 판정을 반환하는 경로가 정상적으로 동작하였다.

`needsReview: true`는 호출 실패를 의미하지 않는다. 이번 결과는 **위험이 감지되었으나 메시지 본문 영역 구분이 불확실하여 추가 검토가 필요하다**는 의미다.

## 4. 응답 지연 및 연동 결함 점검

직접 텍스트 분석은 약 21ms, OCR을 포함한 캡처 분석은 약 6.8초로 보고되었다. 두 입력 방식의 처리 시간을 기록하였으며, 반복 호출에 따른 평균·최대 시간이나 BE 전체 왕복 시간은 이번 결과에 별도로 포함하지 않았다.

공유된 두 테스트에서 분석은 모두 완료되었고, 호출 실패나 별도 수정이 필요한 연동 오류는 보고되지 않았다. `UNCERTAIN_MESSAGE_LAYOUT`은 분석 품질에 대한 검토 사유로, 연동 결함과 구분하였다.

## 5. 결론

텍스트 직접 입력의 BE 호출과 문자 캡처의 OCR API 호출에서 정상 응답을 확인하였다. 분석 결과와 처리 시간, 추가 검토 필요 여부가 반환되는 것을 확인하여 **기본 AI 호출 및 처리 시간 점검을 완료하였다.**

이번 결과는 두 입력 사례의 기능·호출 확인 기록이며, 모델의 전체 오탐률·미탐률이나 출시 성능을 검증한 결과와는 구분한다.
