# Baseline 실험 공유 보완·검수 결과

검수일: 2026-10-05
작업 브랜치: chore/1-baseline-sharing

## 결론

공유 사본의 개인 경로·누락 링크·재현 안내·줄바꿈 처리를 보완했다. 원본 실험 폴더와 고정 추론·판정·평가 코어는 변경하지 않았다. 커밋·push·GPU 재추론은 수행하지 않았다.

## 보완 내용

| 발견 사항 | 처리 |
|---|---|
| 개인 PC 절대 경로 | 공유 보고서와 보고서 생성 보조 코드의 경로를 정리했다. RAISE CSV 경로는 --metadata로 직접 입력한다. |
| 드라이브·CPU 고정값 | record_start.py의 디스크 조회는 프로젝트가 있는 볼륨을 사용한다. cpu_probe.py는 실제 CPU 이름을 --cpu-name으로 필수 입력한다. |
| 보고서 링크 7개 누락 | 집계 그래프 3개와 초기 보조 보고서를 추가했다. 사진 포함 예시 2개는 공개 사본에서 제외 이유를 표시했다. 로컬 runs 링크는 공개 참조 자료로 연결했다. |
| 재현 안내·고정 목록 누락 | handoff/에 Windows 환경·모델 리비전·가중치 해시·입력 목록·고정 분할·과거 평가 요약을 추가했다. |
| 설치 목록 2종 누락 | Mesorch와 v02-data 추론 의존성 목록, 네 환경의 원래 버전 스냅샷과 설치 안내를 추가했다. |
| 과거 결과 복사로 추론 생략 위험 | prepare_replay.py는 네 초기 JSON만 복원한다. 과거 v0.2 점수·freeze·completion·evaluation은 복원하지 않는다. 기존 활성 폴더가 있으면 중단한다. |
| core.autocrlf=true 해시 변경 위험 | .gitattributes에서 코드·참조 바이트를 보존한다. .editorconfig에서도 해당 파일의 자동 줄바꿈·끝줄 정리를 해제했다. |
| 참조 폴더가 Git에서 제외될 위험 | 공개 참조의 디렉터리 이름은 experiments와 input-lists로 구분했다. 활성 runs/, data/ 제외 규칙은 유지했다. |
| README 안내 부족 | 실제 재현 가이드와 v0.1·v0.2 결과 링크를 연결했다. |

과거 준비·완료 스크립트 record_start.py, finish_artifacts.py, verify_followup.py는 원래 PC의 v0.1·폴더 이동 이력 등을 전제로 한다. 새 PC의 범용 시작/완료 도구로 쓰지 않는다고 가이드에 명시했다. 자동 설치·범용 다운로드까지 완성했다는 의미는 아니다.

## 원본과 공유 사본의 구분

원래 scripts·tests·requirements 71개 중 66개는 원본과 바이트가 같다. 보조 코드 5개는 경로·장비 기록 보완으로 변경했다. 이 변경은 모델 계산·공식 전처리·판정 기준을 바꾸지 않는다.

[변경 전후 해시](../handoff/PUBLIC_COPY_PROVENANCE.json)에 보조 코드와 공개 보고서의 출처·SHA-256을 기록했다. 원래 code_sha256 목록은 original_code_sha256.json, 공유 사본 목록은 code_sha256.json이다. 공개 참조 inventory는 배치 변경에 맞춰 재작성했다. 원래 실험의 정책 freeze와 입력 파일은 변경하지 않았다.

## 검증 결과

- 기존 단위 테스트 15개와 v0.2 평가·분리 테스트 6개가 통과했다.
- 새 복원 안전성 테스트 3개도 통과하여 총 24개가 통과했다: 초기 파일만 복원, 기존 결과 보존, 변조된 참조 입력 차단을 확인한다.
- 모든 모델의 원래 v0.2 freeze가 참조하는 자체 코드 해시를 유지했다.
- 참조 묶음 50개 파일의 무결성을 확인했다.
- README와 공개 보고서의 로컬 링크 17개가 존재한다.
- scripts·reports·handoff에서 원래 개인 PC 절대 경로가 남지 않았는지 검사했다.
- 임시 Git 저장소에서 core.autocrlf=true, add, 새 checkout을 수행하여 최종 126개 코드·참조 파일 바이트가 일치했다. 사용자 저장소의 인덱스·커밋은 변경하지 않았다.
- 초기 네 파일 복원, v0.1 목록 추가 복원, 반복 복원 거부, 입력 변조 거부를 별도 임시 폴더에서도 확인했다.

실제 테스트 명령:

~~~powershell
& '<검증 환경의 python.exe>' -X utf8 -m unittest discover -s tests -v
& '<검증 환경의 python.exe>' -X utf8 scripts/v02/test_science.py -v
~~~

테스트는 원래 Python 3.9.13 B-Free 환경에서 복사된 저장소를 대상으로 수행했다. 새 팀원 컴퓨터에서 패키지 설치와 전체 GPU 추론이 통과했다는 의미는 아니다.

## 팀원이 추가로 준비할 자산

- 고정 목록의 이미지·정답 마스크
- 고정 리비전의 공식 소스와 최종 가중치
- 네 Python 환경과 호환되는 NVIDIA GPU

사진·마스크·가중치·추론 지도·개별 점수·가상환경은 공개 저장소에 포함하지 않았다. 이용 조건에 맞는 별도 전달 또는 공식 확보가 필요하다. 설치 버전 스냅샷은 완전한 wheel 해시 lock이 아니다. 상세 절차는 [재현 가이드](../handoff/TEAM_REPRODUCIBILITY_20261004.md)를 따른다.
