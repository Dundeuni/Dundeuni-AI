# 든든이 AI API 문서

이 폴더는 AI API의 요청·응답 계약과 처리 규칙을 코드 버전에 맞춰 관리한다.
API를 변경할 때 코드·명세·응답 예시를 같은 PR에서 갱신한다.

- [이미지 분석 API v0.2](./image-analysis-v0.2.md)에서 CuRe·TruFor의 입력·출력·판정·오류·재시도 규칙을 설명한다.
- 모델 선정 근거와 BE·FE 협의는 명세에 연결한 Notion 문서를 참조한다.
- 구현한 규칙과 협의·검증 대기 항목을 구분한다.

BE의 Swagger·저장소 문서 병행 방식에 맞춰 이 폴더를 구성한다.
현재 AI 코드의 Swagger UI는 비활성화돼 있으며, 요청은 직접 multipart로 파싱하고 응답은
`JSONResponse`로 반환한다. 자동 OpenAPI 문서의 요청·응답 스키마 보강과 UI 제공은
후속 코드 작업으로 진행한다. 이 문서를 자동 생성된 Swagger 미러로 표시하지 않는다.
