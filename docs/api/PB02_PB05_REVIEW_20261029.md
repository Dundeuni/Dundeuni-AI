# PB-02/05 이미지 출력 및 PB-05 이미지·텍스트 계약 점검

업무 항목 기준일: 2026-10-29 (KST)

AI 내부 응답 검증 및 이미지·텍스트 계약 차이 확인을 완료했다. 모델·OCR 대역을 사용하는 API 계약 테스트를 수행했다.

## PB-02/05: 이미지 출력·판단 불가·실패 응답

이미지 전체 기존 테스트 189개가 통과했다.

- 정상 응답의 모델 상태·점수·판정·정책 버전 확인.
- 판단 불가 시 `SUCCEEDED`와 `INCONCLUSIVE` 유지, `displayScore=null` 확인.
- 일부 실패 시 `PARTIAL_FAILED`, 성공 모델 결과 보존, 실패 모델 점수·판정·위치의 null 처리 확인.
- 전체 실패 시 `FAILED`, 대표 판단 불가 및 모델별 오류 보존 확인.
- 입력·인증 오류의 HTTP 상태와 오류 응답 확인.
- 대표 판정의 의심 우선·판단 불가·신호 없음 규칙 확인.
- 저장된 이미지 응답 예시 7개의 `Envelope` 스키마 검증 통과.

## PB-05: 이미지·텍스트 출력 포맷·예외 응답 비교

텍스트 API·OpenAPI 테스트 40개가 통과했다. 이미지·텍스트 각 계약을 검증하고 다음 차이를 정리했다.

| 항목 | 이미지 내부 API | 텍스트 내부 API |
| --- | --- | --- |
| 계약 버전 | `1.0` | `text-risk-1.0` |
| 판단 보류 | `INCONCLUSIVE`, root `COMPLETED` 가능 | `defer`, `COMPLETED` |
| 점수 | `rawScore`, `displayScore` 0~100 또는 null | `riskScore` 0~1 또는 null |
| 모델·처리 실패 | HTTP 200 envelope의 `FAILED`·`PARTIAL_FAILED` 가능 | 처리 실패 503, OCR 실패 502, OCR timeout 504 등 |
| 오류 본문 | 추적·분석·요소 ID와 `error`, `retryable` 포함 | `requestId`, `error.code`, `error.message` |
| 인증 실패 | 401 `AUTHENTICATION_FAILED` | 401 `UNAUTHORIZED` |
| 요청 형식 오류 | 400 `INVALID_REQUEST` | 422 `INVALID_REQUEST` 등 |
| 혼잡 | 503 `AI_BUSY`, 기본 재시도 안내 1초 | 503 `ANALYZER_BUSY`, 재시도 안내 2초 |

판단 보류와 실행 실패를 구분하고, 점수의 단위와 null 및 원래 오류 코드를 보존하는 처리 원칙을 확인했다. 도메인별 응답 포맷은 각 계약을 유지한다.
